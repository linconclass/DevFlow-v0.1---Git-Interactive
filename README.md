# DevFlow — Git Interactive

Um laboratório visual, mobile-first, para aprender desenvolvimento **vendo o fluxo acontecer**.

## v0.1
O primeiro módulo transforma conceitos essenciais de Git em uma experiência interativa: Working Directory → Staging → Commit → Remote.

### MVP atual
- Home mobile-first
- Visual Flow de Git
- Git Playground interativo
- Estados de arquivo e execução sequencial de comandos
- Lista de comandos essenciais e progresso visual
- Interface responsiva inspirada em ferramentas de desenvolvimento

## Stack
React · TypeScript · Vite

## Rodando localmente
```bash
npm install
npm run dev
```

## Roadmap
Git Essentials → branches/merge/conflicts → desafios → Java → Spring → SQL → Docker.
